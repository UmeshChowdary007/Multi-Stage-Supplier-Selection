Optimizing Medicine Supply Chains Using Dynamic Programming

Find the minimum-cost path through suppliers, manufacturers, distributors and hospitals using Dynamic Programming.

Explore Algorithm

Problem Statement

A medicine passes through four sequential stages: Raw Material Supplier, Manufacturer, Distributor and Hospital. Each stage contains multiple options, and every transition has an associated cost.

The objective is to select exactly one option from each stage so that the total supply-chain cost is minimized.

Four Stages of the Supply Chain

01

Raw Material Supplier

Provides ingredients required for medicine production.

R1 | R2 | R3
02

Manufacturer

Converts raw materials into finished medicines.

M1 | M2 | M3
03

Distributor

Stores and transports medicines to healthcare facilities.

D1 | D2 | D3
04

Hospital

Receives medicines for patient treatment.

H1 | H2 | H3

Complexity Analysis

Algorithm Time Complexity Space Complexity
Brute Force O(NS) O(S)
Dynamic Programming O(S × N²) O(S × N)

For 4 stages with 3 options per stage, brute force checks 34 = 81 complete paths. Dynamic Programming reuses previously computed subproblems to reduce repeated work.
